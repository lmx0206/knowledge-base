══════════════════════════════════════════════
  Quick Terminal（Quake 风格下拉终端）
══════════════════════════════════════════════

  Quick Terminal 是一个可以从屏幕边缘滑出的终端窗口，
  类似 Quake 游戏的控制台。

  默认快捷键：无（需自定义配置）

  推荐配置（添加到 config 文件）：
  keybind = global:cmd+backquote=toggle_quick_terminal

  配置后：Cmd + `（反引号）可在任何应用中呼出/隐藏终端

  特点：
  - 全局快捷键，即使 Ghostty 不在前台也能使用
  - 状态保持，隐藏后再次打开显示同样的内容
  - 同一时间只能有一个 Quick Terminal

══════════════════════════════════════════════
  搜索功能
══════════════════════════════════════════════

  Ghostty 目前不内置搜索功能（截至 1.3.x）。

  替代方案：
  1. 使用 Cmd + K 清屏前，用 Cmd + Shift + J 导出 scrollback
     然后在文本编辑器中搜索

  2. 使用 tmux 的搜索功能：
     Ctrl+B 然后 [ 进入复制模式，然后 Ctrl+S 搜索

  3. 自定义快捷键将 scrollback 写入文件并打开：
     keybind = ctrl+f=write_scrollback_file:open

══════════════════════════════════════════════
  自定义快捷键语法
══════════════════════════════════════════════

  基本格式：keybind = 触发器=动作

  触发器格式：修饰键+键=动作

  示例：
  keybind = cmd+shift+t=new_tab
  keybind = cmd+shift+w=close_surface
  keybind = ctrl+f=write_scrollback_file:open

  触发器前缀：
  - global:    全局快捷键（即使不在前台也生效，仅 macOS）
  - all:       对所有终端面板生效
  - unconsumed: 不消费输入（同时发送给子进程）
  - performable: 仅在可执行时消费输入

  示例（全局 Quick Terminal）：
  keybind = global:cmd+backquote=toggle_quick_terminal
