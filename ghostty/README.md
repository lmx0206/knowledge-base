## 什么是 Ghostty？

Ghostty 是一个快速、功能丰富、跨平台的终端模拟器，具有以下特点：

- GPU 加速渲染 — 极快的显示速度
- 原生 UI — 在 macOS 上使用原生 macOS 界面
- 零配置即可使用 — 开箱即用，内置 JetBrains Mono 字体
- 支持数百个配置选项 — 完全自定义
- 内置数百个主题 — 支持亮色/暗色模式切换
- Split 分屏 — 原生支持分屏操作
- Quick Terminal — Quake 风格的下拉终端
- Tab 标签页 — 多标签管理
